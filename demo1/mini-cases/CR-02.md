# Mini case CR-02 — Product-card labels from product tags

> Practice project, fictional brand (Skinhale), Shopify development store, Horizon 4.3.0. Not client work. Built with an AI coding agent (see the [README](../../README.md)).

**Request:** "Products tagged `badge:New` show 'New' as a small label on product cards. We can switch the labels off and choose a style."

**Editor clip (≤90 s):** _to record (owner): Theme settings → Badges → Tag badges: off/on, Filled ↔ Outline._ <link>

## Change log
| File | Change | Why |
|---|---|---|
| `blocks/_product-card-gallery.liquid` | Loop over `product.tags`; a tag starting with `badge:` (any case) adds a label with the rest of the tag; max 2 | The card does not accept custom blocks (checked in a proof of concept), so the existing badge area is extended |
| `snippets/product-badges-styles.liquid` | Badges stack and wrap; Filled / Outline styles from the primary button colour | Long text must never be cut; the colour follows the merchant's brand setting |
| `snippets/card-gallery.liquid` | Tag labels count as badges | Keeps a no-image card's title clear of the label |
| `config/settings_schema.json`, `locales/*.schema.json` | "Show tag badges", "Tag badge style" under Theme settings → Badges | Merchant control without code |

## How to edit (for the merchant)
- **Add a label:** Admin → Products → open a product → Tags → add `badge:Your text` (e.g. `badge:New`). Keep it to 1–3 words.
- **Remove it:** delete the tag.
- **Turn all labels off / change the style:** Online Store → Themes → Customize → Theme settings → Badges → Tag badges.
- Up to 2 labels show per card. "Sale" / "Sold out" always come first.
