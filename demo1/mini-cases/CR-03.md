# Mini case CR-03 — Product details from metafields

> Practice project, fictional brand (Skinhale), Shopify development store, Horizon 4.3.0. Not client work. Built with an AI coding agent (see the [README](../../README.md)).

**Request:** "Show Key ingredients, Skin type and How to use on the product page when they are filled, and hide what is empty."

**Editor clip (≤90 s):** _to record (owner): product page → Product details list block → change a label → it updates; then a product without data shows nothing._ <link>

## Change log
| File | Change | Why |
|---|---|---|
| `blocks/product-details-list.liquid` (new) | Reads `custom.key_ingredients`, `custom.skin_type`, `custom.how_to_use`; one row per filled field; nothing at all when all are empty | The product details column accepts theme blocks, so a block the merchant can move or remove fits best |
| `templates/product.json` | Block placed after the description | Same JSON the editor would save; reproducible from Git |
| `locales/*.schema.json` | 8 editor labels | Theme Check requires every locale file to have them |

## How to edit (for the merchant)
- **Fill the data:** Admin → Products → open a product → Metafields: Key ingredients (one per line), Skin type, How to use (one step per line).
- **Change the labels or heading:** Customize → Products → Default product → Product details list.
- **Move or hide the block:** drag it in the left panel, or click the eye icon.
- A product with none of the three fields shows nothing (no empty heading).
