# Mini case CR-04 — Collection description "Show more / Show less"

> Practice project, fictional brand (Skinhale), Shopify development store, Horizon 4.3.0. Not client work. Built with an AI coding agent (see the [README](../../README.md)).
> The request mirrors a small real job post (collection description toggle); rebuilt here on Horizon with fictional data.

**Request:** "Show only the start of a long collection description with a 'Show more' link, so shoppers see products first. The full text must stay on the page for SEO."

**Editor clip (≤90 s):** _to record (owner): Theme settings → Collection description: words 30 → 15, label "Read more", switch off._ <link>

**Before / after:** [D1_before_collection-full_390w_chromium-headless_20261022.png](../images/D1_before_collection-full_390w_chromium-headless_20261022.png) → [D1_CR04_col-shop-all-collapsed_390w_chromium-headless_20261024.png](../images/D1_CR04_col-shop-all-collapsed_390w_chromium-headless_20261024.png) and [expanded](../images/D1_CR04_col-shop-all-expanded_390w_chromium-headless_20261024.png). Note: the "before" description was 6 words; the 119-word text is test data added for this CR.

## Change log
| File | Change | Why |
|---|---|---|
| `blocks/collection-description.liquid` (new) | Same settings as the text block; long text → first N words + "…" and a native `<details>` toggle; otherwise renders exactly like before | The description used Horizon's generic text block, which renders most text on the site; wrapping it avoids any change elsewhere |
| `templates/collection.json` | The description block uses the new type (its saved settings unchanged) | Only the collection page changes |
| `config/settings_schema.json`, `locales/*.schema.json` | Theme settings → Collection description: on/off, words shown (15–60), both labels | Merchant control without code |

## How to edit (for the merchant)
- **Write the description:** Admin → Products → Collections → open a collection → Description.
- **Change the length or labels / switch it off:** Customize → Theme settings → Collection description.
- Descriptions shorter than the word count show in full with no link.
